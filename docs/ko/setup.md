# 설정과 등록

## 빌드와 업로드
```bash
pio run -e weather-xiao -t upload
pio device monitor -b 115200
```
딥슬립 펌웨어를 올린 뒤 재업로드에는 다운로드 모드 필요: BOOT를 누른 채 RESET.

## Wi-Fi 설정
빌드 전 수정할 것 없음. 보드가 직접 Wi-Fi 설정 요청. 저장된 네트워크가 없으면 AP를 띄우고 e-Paper에
안내 표시:

1. 휴대폰으로 `XIAO-ESP32-C3` 네트워크 접속
2. 브라우저에서 `192.168.4.1` 접속 후 사용할 네트워크 선택

자격증명은 Wi-Fi 드라이버 전용 NVS 네임스페이스에 저장. 펌웨어를 다시 올려도 유지.

네트워크 변경: 접속에 다섯 번 연속 실패하면 보드가 이 화면을 다시 띄움. RESET 다섯 번 연타(접속이
끝나기 전에)로도 바로 같은 상태로 진입. 5분 동안 설정이 없으면 저장된 값을 그대로 두고 다시 딥슬립.

## 보드 등록
서버는 계정에 등록된 보드에만 날씨 전송.

1. Wi-Fi가 연결되면, 서버가 모르는 보드는 코드와 QR을 화면에 띄우고 깨어남 타이머 없이 딥슬립.
   그 사이 서버 확인 없음
2. QR을 스캔하면 코드가 채워진 대시보드가 열림. 로그인 후 보드 등록. Claude나 ChatGPT에 코드를 알려
   줘도 MCP로 등록 가능
3. RESET 누르기. 이 wake에서 서버에 다시 확인하고 날씨 표시

- 코드는 쓰일 때까지 그대로 유지. 서버가 한 시간 뒤 코드를 지웠어도 다음 확인 때 다시 등록됨
- 주인이 보드 등록을 해제하면 서버가 그 보드의 토큰을 모르게 되고, 보드는 다음 wake에 새 코드 표시
