# 배터리 누설전류 Trouble shooting

보드: XIAO ESP32-C3 (mac E8F60A17AF28), e-Paper: Waveshare 1.54" V2.1

---

## 1. 증상

2026-10-06부터 배터리가 평소보다 훨씬 빨리 닳았다. 평소 시간당 1.5 mV 정도 떨어지던 전압이 시간당
9 mV 정도로 떨어졌다.

---

## 2. 시도한 것들

| 시도 | 결과 |
|---|---|
| 예전 펌웨어(d03bffd)로 되돌림 | 똑같이 빠름 |
| 온습도 센서(SHT40) 제거 | 변화 없음 |
| 배터리 교체 | 똑같이 빠름 |
| 배터리 전압 분압기 점검 | 이상 없음 |
| 자는 동안 RST를 HIGH로 고정 (7110254) | 대부분 그대로 빠름 (−3.6 ~ −10 mV/h) |
| e-Paper 모듈 교체 (10-16, 10-18) | 13시간쯤 정상이다가 다시 빨라짐 |
| 자는 동안 패널 선이 0 V와 3.3 V를 오가는 걸 발견, 전부 고정. RST는 HIGH (0e14a8d) | 그대로 빠름 (−7.6 mV/h) |

---

## 3. 문제 해결

자는 동안 패널로 가는 선(RST, CS, DC, CLK, DIN)을 전부 LOW로 고정했다 (f880792). 코드는
`display.cpp`의 `displayHoldPins()`이고, 잠들기 직전 `deepSleep()`에서 부른다.

2026-10-21 15:52에 올린 뒤 6일 동안 시간당 0.76 mV로 떨어졌다. 고장 전 평소(1.5 mV/h)보다도 낮다.

| 펌웨어 | 기간 (독일 시각) | 배터리 | 시간당 |
|---|---|---|---|
| 7110254 | 10-19 11:15 – 10-20 14:27 | 3966 → 3866 mV | −3.6 mV |
| 0e14a8d | 10-20 15:40 – 10-21 15:28 | 4172 → 3990 mV | −7.6 mV |
| f880792 | 10-21 17:35 – 10-28 01:53 | 3970 → 3862 mV | −0.76 mV |

f880792는 커밋 전 상태로 올려서 대시보드에는 `0e14a8d-dirty`로 나온다.

---

## 4. 원인 분석

V2.1 보드에서는 RST가 LOW여야 모듈 전원이 꺼진다. HIGH거나 떠 있으면 자는 동안에도 모듈이 켜져
있어서 전류가 계속 흐른다.

펌웨어는 자는 동안 RST를 LOW로 둔 적이 없었다.

| 펌웨어 | 자는 동안 RST | 모듈 |
|---|---|---|
| 7110254 전 | 고정 안 함 (떠 있음) | 켜짐 (BUSY 3.3 V) |
| 7110254, 0e14a8d | HIGH | 켜짐 |
| f880792 | LOW | 꺼짐 |

RST 말고 다른 선도 전부 LOW로 둔 이유: 모듈이 꺼진 상태에서 HIGH인 선이 있으면 그 선을 타고 모듈로
전류가 샌다.

**아직 설명 안 되는 것**
- 7110254에서 RST가 HIGH였는데도 10-16 21:00 – 10-17 10:33에는 −1.2 mV/h로 정상이었다.
- 하필 10-06에 시작된 이유.
